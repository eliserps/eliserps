## Featured Project

### ✈️ [airspace-copilot](https://github.com/eliserps/airspace-copilot)

An AI copilot that explains live air traffic and aviation weather in plain English or Portuguese.

[![CI](https://github.com/eliserps/airspace-copilot/actions/workflows/ci.yml/badge.svg)](https://github.com/eliserps/airspace-copilot/actions/workflows/ci.yml)

<a href="https://github.com/eliserps/airspace-copilot">
  <img src="https://raw.githubusercontent.com/eliserps/airspace-copilot/main/docs/demo.gif" alt="Airspace Copilot: live aircraft on a 3D globe, the copilot streaming an answer, and the details of a selected aircraft" width="100%" />
</a>

- 🌍 **Live traffic** on a 3D globe, from OpenSky data
- 💬 **Streaming agent** with read-only tools for weather and traffic, so numbers come from data and not from the model
- 🌦️ **METAR decoder** scored against hand-checked answers
- ✅ **163 automated tests** with 97% backend coverage, run by CI on every push
- 📐 **Architecture Decision Records** and frontend types generated from the OpenAPI contract
